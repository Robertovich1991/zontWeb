# Comfort Cars Reservations API

Read-only REST API that returns **Comfort Cars** reservations from the Zont dispatch
system (same rides as the admin "auctions" panel, filtered to Comfort Cars only).

- **Base URL (production):** `https://www.zont.cab/api/partners/comfort-cars`
- **Format:** JSON
- **Access:** read-only
- **Authentication:** API key in the `X-API-Key` header (generated by Zont, shared privately).
  The current key and base URL are visible in the Zont admin panel under **API Comfort Cars**.

> A live, self-describing version of this reference is available (no key required) at
> `GET /api/partners/comfort-cars/docs`.

---

## Authentication

Every request must send the key in the header:

```
X-API-Key: YOUR_KEY
```

Missing or invalid key → `401 Unauthorized`.

---

## Endpoints

### 1. List reservations

```
GET /reservations
```

Returns Comfort Cars reservations, newest first.

**Query parameters (all optional):**

| Param        | Type   | Description                                                        |
|--------------|--------|--------------------------------------------------------------------|
| `date_from`  | string | Ride date `>=` this date. Format `YYYY-MM-DD`.                     |
| `date_to`    | string | Ride date `<=` this date. Format `YYYY-MM-DD`.                    |
| `status`     | string | One of: `pending`, `confirmed`, `assigned`, `in_progress`, `completed`, `cancelled`. |
| `page`       | int    | Page number, `>= 1`. Default `1`.                                  |
| `page_size`  | int    | Results per page, `1..200`. Default `50`.                          |

**Example:**

```bash
curl -H "X-API-Key: YOUR_KEY" \
  "https://www.zont.cab/api/partners/comfort-cars/reservations?status=completed&date_from=2026-06-01&page=1&page_size=50"
```

**Response:**

```json
{
  "data": [ { /* reservation object */ } ],
  "pagination": { "page": 1, "page_size": 50, "total": 128, "total_pages": 3 }
}
```

### 2. Get one reservation

```
GET /reservations/{id}
```

Returns a single reservation, **only if it belongs to Comfort Cars** (otherwise `404`).

```bash
curl -H "X-API-Key: YOUR_KEY" \
  "https://www.zont.cab/api/partners/comfort-cars/reservations/123"
```

## Reservation object

```json
{
  "id": 123,
  "status": "completed",
  "statusRaw": "Completed",
  "date": "2026-06-10",
  "time": "14:30",
  "startDate": "2026-06-10T14:30:00",
  "pickupAddress": "Aéroport CDG, Terminal 2E",
  "dropoffAddress": "12 Rue de Rivoli, Paris",
  "vehicleType": "Van",
  "tripType": "transfer",
  "distanceKm": 28.4,
  "amount": 95.0,
  "currentPrice": 95.0,
  "currency": "EUR",
  "isFixedPrice": true,
  "paymentSuccessful": true,
  "client": { "firstName": "Jean", "lastName": "Dupont", "phone": "+33612345678" },
  "driver": { "firstName": "Max", "lastName": "Petit" },
  "company": "Comfort Cars Paris",
  "comments": "Vol AF1234"
}
```

- `status` is the **normalized** value; `statusRaw` keeps the original dispatch string.
- `driver` is `null` when no driver is assigned yet.

### Status values

| Normalized    | Raw dispatch statuses                                   |
|---------------|---------------------------------------------------------|
| `pending`     | `New`                                                   |
| `confirmed`   | `ApprovedByAdmin`, `Confirmed`                          |
| `assigned`    | `Took`                                                  |
| `in_progress` | `Started`                                               |
| `completed`   | `Completed`                                             |
| `cancelled`   | `CancelledByClient`, `CancelledByDriver`, `Cancelled`, `DontApprovedByDriver` |

---

## Errors

| Code | Meaning                                              |
|------|------------------------------------------------------|
| 400  | Invalid parameter (bad date format or unknown status)|
| 401  | Missing or invalid API key                           |
| 404  | Reservation not found for Comfort Cars               |
| 502  | Dispatch system temporarily unavailable              |
